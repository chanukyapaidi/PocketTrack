# 💰 PocketTrack

PocketTrack is a modern and responsive **personal expense tracker for students**. It helps users track their expenses, manage budgets, analyze spending habits, and understand where their money goes.

The project features a premium dark UI with a subtle **Spider-inspired red and blue visual theme**.

---

## 🚀 Features

- ➕ Add and manage expenses
- 🗑️ Delete expenses
- 💰 Track total spending
- 📊 View expense analytics
- 📂 Categorize expenses
- 🔍 Search and filter expenses
- 📅 Filter expenses by date
- 🎯 Set and track monthly budgets
- 💵 View remaining budget
- 📈 Category-wise spending analysis
- 🌙 Dark and light mode
- 💾 LocalStorage data persistence
- 📥 Export expense data
- 📱 Fully responsive design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Chart.js
